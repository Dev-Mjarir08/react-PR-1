# React PR-1

A modern React.js practice project built to understand and implement core React concepts such as components, props, state management, hooks, lifecycle methods, conditional rendering, and reusable UI structures.

---

## 🚀 Features

- Functional Components
- Class Components
- useState Hook
- useEffect Hook
- Component Lifecycle
- Props Handling
- Conditional Rendering
- Event Handling
- Dynamic UI Updates
- Clean Folder Structure
- Reusable Components

- HTML5
- CSS3

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/Dev-Mjarir08/react-PR-1.git
```

### 2️⃣ Move Into Project Folder

```bash
cd react-PR-1
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start Development Server

```bash
npm run dev
```
